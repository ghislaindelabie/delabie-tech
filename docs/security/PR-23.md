## (2) Security-relevant decisions

- **YAML parsing**: `YAML.safe_load_file(SEED_PATH, permitted_classes: [Date, Time])` — Psych safe variant, only Date/Time permitted (no gadget-chain risk).
- **URL validation**: `url_safe?` regex `\Ahttps?://[^"\s<>]+\z` is anchored with `\A`/`\z`, strictly limiting to HTTP(S) schemes — no `file://`, `ftp://`, `gopher://`, `dict://` reachable.
- **Slug validation**: `slug_safe?` regex `\A[a-z0-9][a-z0-9-]*\z` is anchored, lowercase + hyphens only, no leading hyphen — no path traversal (`..`, `/`, `\`, null bytes all rejected).
- **HTTP defaults**: `Net::HTTP.start(... use_ssl: uri.scheme == "https" ...)` — TLS cert verification is on by default in Ruby ≥ 2.5 (`VERIFY_PEER`). Timeouts capped at 10s.
- **PDF size cap**: 30 MB limit, but enforced post-buffering. Acceptable per local-only threat model.
- **Idempotency**: write_pair refuses to overwrite when EITHER `_archive/<slug>.md` OR `_archive/<slug>.fr.md` exists (REVIEW-4 fix in code review).
- **Whole-hash YAML dump**: front-matter serialization uses `YAML.dump(fm)` once per file rather than per-key concat — strengthens output safety (Psych-driven escaping of quotes, newlines, special characters).
- **Generated body content**: only one item ships a body (`florence-intermodal-2022`); content is plain markdown (headings, prose, italics) — no raw HTML, no Liquid tags, no `javascript:` URLs, no inline data URIs. Rendered through Kramdown identically to `_publications/` bodies (same trust class as PR #22).

## (3) Findings

No HIGH or MEDIUM findings.

### LOW-1: PDF body buffered before size check — `_migration/archive_import.rb:85-86`

- **Severity:** LOW
- **Category:** resource_management (out of scope per threat-model exclusions, but noted)
- **Confidence:** 0.6
- **Status:** Risk accepted.
- **Description:** `response.body` materialises the full HTTP response in RAM before `body.bytesize > max_bytes` is evaluated. A misconfigured server could stream multi-GB content and OOM the local Ruby process before the cap triggers.
- **Rationale (accept):** Author-curated URLs only, run manually, locally, by Ghislain. No untrusted-input boundary. Refactoring to streaming reads would add complexity for a local script that fetches ~30 items once.
