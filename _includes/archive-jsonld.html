{%- comment -%} Per-archive-item Schema.org JSON-LD. Switches by `page.type` to emit the most-specific Schema.org type for each artefact. Replaces the generic `BlogPosting` jekyll-seo-tag would otherwise produce (head.html strips seo-tag's JSON-LD block on archive_item pages) — so search engines index a press citation as a NewsArticle, a recorded talk as a VideoObject, a podcast guest spot as a PodcastEpisode, etc. Type mapping (ARCHIVE_ALLOWED_TYPES → Schema.org): article → NewsArticle oped → NewsArticle (op-ed is journalistic content) quoted → NewsArticle (third-party citation in news content) interview→ InterviewObject (still mostly a Schema.org draft, but better than NewsArticle for the semantic) report → ScholarlyArticle (long-form research output) talk → PresentationDigitalDocument video → VideoObject podcast → PodcastEpisode {%- endcomment -%} {%- assign jsonld_type = "NewsArticle" -%} {%- case page.type -%} {%- when "article", "oped", "quoted" -%}{%- assign jsonld_type = "NewsArticle" -%} {%- when "interview" -%}{%- assign jsonld_type = "InterviewObject" -%} {%- when "report" -%}{%- assign jsonld_type = "ScholarlyArticle" -%} {%- when "talk" -%}{%- assign jsonld_type = "PresentationDigitalDocument" -%} {%- when "video" -%}{%- assign jsonld_type = "VideoObject" -%} {%- when "podcast" -%}{%- assign jsonld_type = "PodcastEpisode" -%} {%- endcase -%}
